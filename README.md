# Cross Space Attacks

This repository contains code, datasets, and experiments for analyzing cross-space attacks involving GPS spoofing and LiDAR spoofing using the KITTI dataset.

## Repository Structure

| File                           | Description                                                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `00.txt`                       | Ground truth trajectory for KITTI Sequence 00.                                                                    |
| `gps_positions.csv`            | GPS measurements for KITTI Sequence 00.                                                                           |
| `gps_spoof.ipynb`              | Generates spoofed GPS trajectories from the original GPS data.                                                    |
| `new_traj_0_2.csv`             | Spoofed GPS trajectory generated by `gps_spoof.ipynb`.                                                            |
| `normal_traj.txt`              | Vehicle trajectory estimated by A-LOAM without spoofing (generated using SlamSpoof).                              |
| `spoofed_traj.txt`             | Vehicle trajectory estimated by A-LOAM under LiDAR spoofing (generated using SlamSpoof).                          |
| `transform_axes.m`             | Transforms LiDAR and GPS trajectories into a common coordinate frame for comparison and sensor fusion.            |
| `normal_traj_transformed.csv`  | Transformed normal LiDAR trajectory.                                                                              |
| `spoofed_traj_transformed.csv` | Transformed spoofed LiDAR trajectory.                                                                             |
| `ESKF.m`                       | Error-State Kalman Filter implementation that estimates the vehicle state using LiDAR, GPS, and IMU measurements. |
| `simultaneous_spoof.ipynb`     | Observation-space vulnerability analysis for LiDAR spoofing attacks.                                              |

## Data Processing Pipeline

1. Start with the KITTI Sequence 00 ground truth (`00.txt`) and GPS measurements (`gps_positions.csv`).
2. Generate spoofed GPS trajectories using `gps_spoof.ipynb`, producing `new_traj_0_2.csv`.
3. Run A-LOAM with SlamSpoof (https://github.com/Keio-CSG/slamspoof) to obtain:

   * `normal_traj.txt`
   * `spoofed_traj.txt`
4. Transform GPS and LiDAR trajectories into a common coordinate frame using `transform_axes.m`.
5. Use the transformed trajectories together with IMU measurements in `ESKF.m` for state estimation.
6. Perform observation-space vulnerability analysis using `simultaneous_spoof.ipynb`.

## Notes

* The experiments are based on KITTI Sequence 00.
* LiDAR trajectories are generated using A-LOAM integrated with SlamSpoof.
* GPS and LiDAR trajectories are transformed into a common coordinate frame before sensor fusion and analysis.
